# Code of Conduct

This project is a place for technical work. Everyone who takes part, in issues, pull requests
and discussions, is expected to:

- be respectful and stay on the subject;
- criticize code and ideas, not people;
- accept that the maintainer decides what is merged and what is not.

Harassment, insults, discrimination and publishing other people's private information are not
acceptable.

The maintainer may edit or remove comments, close issues and pull requests, and block accounts
that break these rules, without prior notice.

To report a problem, write to **licensing@prontea.de** with the subject "Conduct". Reports are
treated confidentially.
