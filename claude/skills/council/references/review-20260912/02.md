## When NOT to Use

| Instead of council | Use |
| --- | --- |
| Verifying whether output is correct | run/verify it yourself (tests, execution) |
| Breaking a feature into implementation steps | plan mode / a normal plan |
| Designing system architecture | the `architecture` / `system-design` skills |
| Reviewing code for bugs or security | `/code-review` or `/security-review` |
| Straight factual questions | just answer directly |
| Obvious execution tasks | just do the task |
