# council

Write the decision, material alternatives and your initial recommendation first. Use only the context that can change the choice. Separate architect (coherence), skeptic (premise), pragmatist (effort) and critic (failure impact).

Independent agents are useful only for an explicitly requested council or a consequential unresolved tradeoff. Use available delegation and allowed models; do not require a named provider or start three agents for routine work. Without delegation, give a clearly labelled analysis from these perspectives, not a claim of independent votes.

Each independent response gives position, reason and principal risk. Synthesize disagreements against evidence, explain the chosen tradeoff and proceed within existing authorization. No automatic cross-read or subsequent review round; `~/.claude/regeln/verifikation.md` governs additional checks.
