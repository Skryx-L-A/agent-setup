# Neues Projekt, neue Website

Auslöser: bevor bei einem NEUEN Projekt Code oder Architektur entsteht, und bevor eine Website
oder eine Web-Oberfläche gestaltet wird. Ausgelagert aus `CLAUDE.md` am 2026-08-27 — beide Regeln
greifen nur bei diesen Tätigkeiten, nicht in jeder Session.

## grill-me bei jedem NEUEN Projektstart

Skill `~/.claude/skills/grill-me/`. Vor Code und vor Architektur wird interviewt: **eine Frage
nach der anderen**, jeweils mit einer empfohlenen Antwort. Ungefragt, nicht auf Zuruf.

Der Sinn ist, die Annahmen aus dem Kopf des Auftraggebers auf den Tisch zu holen, solange
Umentscheiden noch nichts kostet. Wer erst baut und dann fragt, verhandelt gegen den eigenen
Code.

## framer-inspiration bei jedem Website-Bau

Skill plus `framer-inspo`-CLI. Gestaltungsanregungen aus Framers öffentlichen Galerien werden
**automatisch und vor dem Entwurf** geholt, auch wenn Framer im Auftrag nie vorkommt.

Ausschließlich als Anregung: **keine Assets und kein Code werden übernommen**, und gebaut wird
nie in Framer selbst.
