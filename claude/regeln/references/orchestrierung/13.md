### Kurztabelle: welche Stufe für welche Arbeit

**Right-size worker models (mandatory), nach erwarteter Gesamtarbeit und nicht nach
„Wichtigkeit", so günstig wie möglich ohne Qualitätsverlust** (2026-07-12). Das Routing
(freigegeben 2026-07-25, Namen wie `claude-worker` sie annimmt) gilt erst, wenn `qwen38` lokal
nicht reicht (Codex-Spalte seit 2026-09-11 gleichrangig, Wahl zwischen den Abos nach
Tagesbudget, Abschnitt „Codex neben Claude"):

| Aufgabe | Worker |
|---|---|
| Bulk / Inventur / DSGVO / Overnight | lokale pi-Worker (`ornith`, `ornith9`) |
| mechanisch: rename, config tweak, format, ein offensichtlicher Fix | `haiku45:low` |
| sehr kurz + klarer Coding-Auftrag | `codex-gpt-5-3-codex-spark:low` |
| kurz + gut spezifiziert | `sonnet5:high` oder `codex-gpt-5-6-luna:medium` |
| größer, aber Spez klar: Cross-File-Refactor, Testsuite, Doku-Sweep | `sonnet5:xhigh` oder `codex-gpt-5-6-terra:high` |
| lang/mehrstufig, Debugging, Design-Entscheidungen, Ambiguität | `opus5:xhigh` oder `codex-gpt-5-6-sol:xhigh` |
| unabhängiger Reviewer-Pass | `opus5:high` oder `codex-gpt-5-6-sol:high` (bevorzugt die andere Familie als der Bauer) |
| Zweitmeinung / A-B | `opus48:xhigh` |
| klare Bildgenerierung oder Bildbearbeitung | `codex-gpt-5-6-luna:medium` plus GPT-Bildwerkzeug |
| komplexe Art Direction oder iterative Bildkritik | `codex-gpt-5-6-sol:high` plus GPT-Bildwerkzeug |
| Computer Use, klarer Ablauf | `codex-gpt-5-6-terra:medium` |
| Computer Use, lang oder fehleranfällig | `codex-gpt-5-6-sol:high` |
| kundengerichtetes visuelles Deliverable (Landing-Page, Kundenpräsentation, visuelles Asset für Kunden) | `opus5:xhigh` oder `codex-gpt-5-6-sol:xhigh` |

Die Begründungen dazu, bis 2026-08-28 in `roles/orchestrator.md`:

- **Opus 5 kostet exakt so viel wie Opus 4.8 ($5/$25 pro MTok) und ist deutlich besser.** Es gibt
  keinen Kostengrund mehr für harte Tasks auf 4.8; 4.8 bleibt für Zweitmeinung und Vergleich, nicht
  als Default.
- **Sonnet 5 ist keine Sparversion** ($3/$15, near-Opus bei Coding und Agentik, volle
  Effort-Leiter). „Mehrere Dateien, Spez klar, aber nicht trivial" gehört zu Sonnet 5 und nicht zu
  Opus: Token-Effizienz ohne Qualitätsverlust.
- **Haiku 4.5 hat nur 200K Kontext** (alle anderen 1M): keine großen Repo-Sweeps an Haiku.
- **Undersizing kostet mehr als Oversizing.** Ein Worker, der loopt oder einen Redo braucht, ist
  teurer als eine Stufe zu viel. Beispiel in beide Richtungen: Opus auf einem Rename verbrennt
  Budget; Sonnet auf einem zähen Multi-Step-Task verbrennt mehr.

Die vollständige Registry-Tabelle (alle Harnesses, alle Fremdmodelle, je mit Eignung) steht in
`~/.claude/roles/orchestrator.md` und wird dort von `wb-instructions sync` erzeugt. Nur der
Orchestrator spawnt, nur er braucht sie geladen. Abfragen ohne Datei: `wb-state models table`.
